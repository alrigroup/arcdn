## Overview

**ARCDN** is a lightweight, high-performance static file server and content delivery node built in pure C for the [ALRIOS](https://github.com/alrigroup/alrios) operating system.

### Features

- 📁 **Static File Serving** — Serve assets with proper MIME types and caching headers
- 🔄 **Hot Reloading** — Detect file changes and serve updated content instantly
- 🔒 **TLS Support** — Native HTTPS via OpenSSL
- ⚡ **Minimal Footprint** — Tiny memory and CPU usage

## Building

```bash
armake build arcdn
```

## Part of ALRIOS

ARCDN is a core component of the [ALRIOS Operating System](https://github.com/alrigroup/alrios).
